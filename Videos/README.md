# Videos de las pruebas

Los cuatro videos CODESYS corresponden exactamente a las corridas conservadas en `Pruebas/`, y muestran visualización y HMI. Sus nombres identifican implementación y variante. La captura fue de 2 cuadros por segundo de tiempo simulado; el README de cada banco documenta sus particularidades de temporización.

El video de la prueba 1 está marcado `Ejecucion_Previa`: corresponde a una ejecución anterior completa, reproducida a aproximadamente 5×. La repetición final que aportó las señales y gráficas se hizo sin video. No se presenta ese video como sincronizado con los datos finales.
